# sunge · 省 token 使用纪律 + 压缩工具

> LLM 会话是有成本的：token 是钱，上下文是占用。
> 这套技能把「每一分成本都花在刀刃上」做成一条可执行的纪律，外加一个零依赖的压缩工具，
> **产出必落地、成本必回收——一个 token 都不白花。**

## 这是什么

`sunge` 是一套面向 LLM 会话的**成本纪律**：把「不能浪费」当成底层原则，落到写码、查资料、改文档、跑长流水线、审长对话等所有场景。token 是钱、上下文是占用，那么——

- **空转白花的 token 就是浪费。** 你的活不是「用 token」，是让每一笔本该白花的成本都被省下来、物尽其用；
- 不挑领域——写码、查资料、改文档、跑长流水线、审一坨长对话，**见哪省哪**；
- 一句话教义：**先想清楚这笔成本该不该花，再动手；动手了就一步到位。**

| 成本原则 | token 世界的落地 |
|---|---|
| 绝不花冤枉钱 | 你的会话可以产出很多，但绝不让一个 token 花在无用输出/空转上 |
| 白花的成本永远不缺 | 全量读、无效重试、无结论发散永远不愁没货；省的就是这些 |
| 没被用上的产出才是真沉没成本 | 读文件没带出结论 = 这次读取白费了，省不回来 |
| 物尽其用 | 每个动作都得回报：读带结论、跑带结果、搜落决策 |
| 只做增量，不重复存量 | 已确认的事实直接引用，不读第二遍、不跑第二遍 |
| 从结果倒推，一次做对 | 动手前想清交付物长什么样，返工是最贵的 |
| 认知杠杆 > 资金杠杆 | 用一次高层规划压平多轮低效试错 |
| 永远站在不浪费的一侧 | 长任务主动压缩/存档，半路断了也已经物尽其用 |

## 七条守则

1. **先立项再动手。** 一句话说清目标 + 最短可行路径。没目标的活 = 必亏。
2. **按需读取，别整 dump。** 用 Glob / Grep / 精准 Read 定位；大文件先读骨再读肉。**但必读文件照读**——漏读必读文件导致的返工，才是最贵的一笔。省错地方 = 搬石头砸脚。
3. **复用已有事实。** 本会话确认过的直接用 `file:line` 引用，不整段复述、不二次推导。
4. **并行与合并。** 多个独立只读动作一个消息齐发；一条命令能干完的别拆三趟。
5. **结论先行，不注水。** 一句话说清的不写三段；输出都给路标(结论 → 依据 → 下一步)，不给观后感。
6. **长会话主动瘦身。** 上下文快满就出手：该摘要摘要、该存档存档、能派子代理就派。别让历史套牢你的窗口。
7. **每次都回收。** 结尾给可执行下一步或明确结论，不留原地打转的空话。

## token 审计

拿一段方案、一个任务、一坨长对话问「费不费 token / 值不值 / 怎么最省」，开一份成本审计单：

```markdown
【结论】一句话——这局整体值不值 / 哪一步是最大的成本漏洞
【浪费点扫描】3~5 个 token 漏洞(参考漏洞库, 照实找, 没有就直说"这局挺干净")
│  每个漏洞给: 位置 + 为什么白花 + 解法(一次定位/按需读/并行/先规划/结论先行)
【真实成本账】这步大概烧多少、省完能省到多少(粗略量级即可, 别装精确)
【一句话收尾】能直接发出去的一句话
```

**漏洞库(浪费点对照表)：**

- 全量读 / 全量 dump → 改按需 + 带行号片段
- 复读存量(已确认的又读一遍/跑一遍) → 直接引用
- 无结论空转(瞎试、重复 retry 被墙命令) → 先查根因或换路
- 无目标发散(一次问一堆不相干) → 先一句话定目标
- 大水漫灌输出(背景/备选展览/冗长解释) → 结论先行
- 该存不存(长会话不压缩不落盘) → 主动瘦身 + 写记忆

## 怎么触发

- 输入 `/sunge`，或直接说：
  - 「帮我省 token」「这个任务会不会很费 token」
  - 「上下文太大了怎么办」「以最少 token 达成 X」
  - 「审一下这方案 / 这段对话值不值」

被触发后，skill 会按 7 条守则执行，或对指定任务跑一份成本审计单——让你知道省在了哪、省出了多少。

## 核心文件结构

```
sunge/
├── SKILL.md                 # 技能本体(守则 + 审计 + 红线 + 省 token 军火库 + 工具调用法)
├── README.md                # 本说明
├── scripts/
│   └── squeeze.py           # 配套工具: 文本压缩 / token 计数 / 代码 AST 骨架化(零依赖)
└── assets/
    └── images/
        └── sunge.png        # 技能配图/logo
```

`SKILL.md` 不只是口号，还带一套**能落地、能调用的省 token 军火库**：滑动窗口+历史摘要、删客套词、AST 骨架化、Lost-in-the-Middle 锚点首尾、max_tokens/stop 收口、省码阶梯、token 纪律工作模式——每一条都从真实会话里磨出来，落成了机械指令。其中能确定性执行的部分做成了 `scripts/squeeze.py`（文本压缩规则 + 自研代码骨架化，Python 3.10+，无第三方硬依赖；装 tiktoken 则 token 计数更准）：

```bash
python scripts/squeeze.py "请写一个函数返回数组之和"        # 压缩 + 省量
python scripts/squeeze.py --explain "Could you please ..."  # 逐规则解释
python scripts/squeeze.py --count <文本>                    # 数 token
python scripts/squeeze.py --skeleton app.py                 # 代码骨架化
```

## 边界(红线)

省 token ≠ 偷工。正确性、安全、必要的验证与必读文件**一样都不能砍**；异常与风险照实讲，不为省 token 隐瞒；审计不编漏洞。省的是成本，不是质量——进了你的代码仓库，工程正确性第一。
