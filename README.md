# sunge · 孙哥(绝不浪费一个 token)

> 把孙宇晨「绝对不能亏」的思维模式通用化，落到 LLM 的 token 经济上。
> **你的会话可以很嗨，但孙哥绝不让一个 token 花在无用功上。**

## 这是什么

`孙学` 不是炒币口诀，而是一套把「**绝对不能亏**」当底层逻辑的**通用思维模式**。搬到 AI / LLM 场景后：

- **token 就是钱，上下文就是仓位** → 目标变成 *绝不白烧一个 token、每个动作颗粒归仓*；
- 不绑定领域——写代码、查资料、改文档、跑长流水线、审一段长对话，全通用；
- 核心一句话：**先想清楚再花，花了必须回收产出。**

| 孙学原教义 | token 世界的翻译 |
|---|---|
| 你可能很赚，但孙哥永远不亏 | 绝不让一个 token 花在无用输出/空转上 |
| 浮亏不是亏 | 但没被用上的输出才是真沉没成本 |
| 颗粒归仓 | 读文件带出结论、跑命令带出结果，空手而归 = 亏 |
| 只做增量，不恋存量 | 不复读已确认的事实，踩着结论往前走 |
| 从未来看正确的事 | 动手前先想清交付物，一次做对，返工是最大的亏 |
| 永远站在不亏的一侧 | 长任务主动压缩/存档上下文，断了也已颗粒归仓 |

## 怎么触发

- 输入 `/sunge`，或直接说：
  - 「按孙哥来跑」「帮我省 token」
  - 「这个任务会不会很费 token」「上下文太大了怎么办」
  - 「审一下这方案 / 这段对话值不值」「以最少 token 达成 X」

被触发后，skill 会按 **7 条通用守则** 执行，或对指定任务/方案跑一份 **孙哥 token 审计单**(裁决 → 白烧点扫描 → 真实成本账 → 判词)。

## 安装 / 使所有项目可用

默认作为 git-killer 项目的 skill 使用(`.claude/skills/sunge/`)。想让**所有项目**都能用，把整个 `sunge` 文件夹拷到用户级技能目录：

```bash
cp -r "D:/Opencode/git-killer/.claude/skills/sunge" "C:/Users/c696r/.claude/skills/"
```

> 改动后需**重启/新开一个会话**才会注册为 `/sunge`。

## 边界(红线)

省 token ≠ 偷工。正确性、安全、必要的验证与必读文件一样不能砍；异常与风险照实讲，不为省 token 隐瞒；审计不编漏洞。人设归人设，工程归工程。
